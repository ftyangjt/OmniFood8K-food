# 后续改进方向

建议选择一个明确方向作为后续工作：

```text
引入食物区域分割和基于深度的体积特征，提升质量和热量估计精度。
```

## 为什么选择这个方向

当前模型虽然使用了 RGB 图和伪深度图，但它仍然直接对整张图进行特征提取。整图中可能包含盘子、桌面、餐具、背景等无关区域。这些区域会干扰模型判断真正的食物面积、厚度和份量。

营养估计中最关键的难点不是只识别食物类别，而是估计份量。质量和热量通常与食物区域面积、厚度和体积强相关。因此，引入食物 mask 和深度体积特征比继续单纯堆大模型更有针对性。

## 具体方案

1. 增加食物区域分割

可以使用现有分割模型得到食物 mask：

```text
RGB 图像 -> segmentation model -> food mask
```

mask 用于过滤背景，只保留食物区域。

2. 基于 mask 提取深度统计特征

在食物区域内计算：

```text
食物区域面积
平均深度
最大深度
深度方差
近似体积特征 area * mean_depth
```

这些特征可以作为额外输入，与 CNN/Transformer 图像特征拼接。

3. 修改模型输入

可以将体积统计特征接入 SharedNutritionHead：

```text
融合图像特征 + 深度体积特征 -> SharedNutritionHead -> 5 个营养值
```

4. 增加消融实验

建议比较：

```text
RGB only
RGB + Depth
RGB + Depth + Mask
RGB + Depth + Mask + Volume features
```

## 预期收益

```text
1. 减少背景干扰
2. 更准确估计食物份量
3. 对 mass 和 calories 提升更明显
4. 推理结果更容易解释
```

## 可能代价

```text
1. 需要额外分割模型
2. 推理速度会变慢
3. 分割错误会影响最终预测
4. 需要设计新的特征融合方式
```

## 汇报时可以这样说

后续工作可以从“更准确地估计份量”入手。当前模型已经使用 RGB-D 双分支，但深度图仍然包含背景区域。我们计划引入食物分割 mask，仅在食物区域内提取深度统计和近似体积特征，再与当前融合特征一起输入共享预测头。这样可以让模型不仅看到食物的类别和纹理，还能显式获得面积、厚度和体积线索，从而提高质量和热量估计的准确性。
