# 项目思路及流程

本文档说明当前项目从数据到结果的完整流程。当前代码已经不是原始重模型版本，而是轻量化后的营养估计流程：

```text
RGB 食物图像 -> 生成/读取深度图 -> RGB/Depth 双分支特征提取 -> 频域与语义融合 -> 共享多任务预测头 -> 输出营养结果
```

当前模型主要预测 5 个营养指标：

```text
热量 calories_kcal
质量 mass_g
脂肪 fat_g
碳水 carb_g
蛋白质 protein_g
```

## 1. 项目目标

本项目用于单张食物图片的营养成分估计。输入是一张食物图片，输出该食物的热量、质量、脂肪、碳水和蛋白质。

这个任务属于回归任务，不是分类任务。模型不是只判断食物类别，而是预测连续数值。

## 2. 当前代码结构

```text
scripts/
  train_nutrition.py       训练入口
  test.py                  测试入口
  infer_nutrition.py       单张图片或文件夹推理入口
  generate_8k_depth.py     批量生成 rgb-d.png 深度图

model/
  myswinb.py               Swin-T 风格 RGB 分支
  convnext1.py             ConvNeXt-Tiny 深度分支
  dual_swin_convnext.py    RGB/Depth 融合网络

modules/
  adapter.py               深度图适配器 DepthAdapterV4
  fusion.py                SharedNutritionHead 共享多任务预测头

utils/
  datasets.py              数据集定义
  utils_data222.py         DataLoader 创建逻辑

data/
  0-OminiFood8k/           OmniFood8K 数据

pth/
  预训练权重

trained_weights/
  训练得到的 checkpoint

outputs/
  推理结果与生成深度图
```

## 3. 数据组织

OmniFood8K 的训练和测试划分由两个文本文件决定：

```text
data/0-OminiFood8k/train_new333.txt
data/0-OminiFood8k/test_new333.txt
```

每一行包含：

```text
sample_id mass calories protein fat carb
```

代码会根据 `sample_id` 找到对应的图片：

```text
data/0-OminiFood8k/1-data/<sample_id>/camera_4.jpg
data/0-OminiFood8k/1-data/<sample_id>/rgb-d.png
```

其中：

```text
camera_4.jpg  RGB 食物图像
rgb-d.png     Depth Anything V2 生成的伪深度图
```

当前输入尺寸统一为：

```text
320 x 320
```

这样可以减少计算量和显存占用，加快训练和推理。

## 4. 深度图生成

如果样本目录中没有 `rgb-d.png`，需要先运行深度图生成脚本：

```powershell
python scripts\generate_8k_depth.py --data-root .\data\0-OminiFood8k --encoder vitl --ckpt .\pth\depth_anything_v2_vitl.pth
```

深度图的作用是提供食物的空间结构和份量线索。营养估计不仅依赖食物类别，也依赖食物体积和质量，因此 RGB-D 信息比单独 RGB 更有帮助。

## 5. 模型流程

当前模型整体结构如下：

```text
RGB 图像
  -> SwinTransformer, Swin-T 风格
  -> RGB 多尺度特征 r1, r2, r3, r4

Depth 图像
  -> DepthAdapterV4
  -> ConvNeXt-Tiny
  -> Depth 多尺度特征 d1, d2, d3, d4

RGB 特征 + Depth 特征
  -> FusionNet_3Branch_UNet_FFT
  -> 融合特征 o1, o2, o3, o4

融合特征
  -> SharedNutritionHead
  -> calories_kcal, mass_g, fat_g, carb_g, protein_g
```

## 6. RGB 分支

RGB 分支使用 Swin-T 风格的 Swin Transformer。

当前配置为：

```text
img_size = 320
embed_dim = 96
depths = [2, 2, 6, 2]
num_heads = [3, 6, 12, 24]
window_size = 10
```

选择 Swin-T 的原因是它比 Swin-B 更轻，训练速度更快，显存占用更低。

## 7. 深度分支

深度分支使用：

```text
DepthAdapterV4 + ConvNeXt-Tiny
```

DepthAdapterV4 用来适配深度图输入，使其更适合送入 ConvNeXt。ConvNeXt-Tiny 用于提取深度图的多尺度空间特征。

ConvNeXt-Tiny 相比 ConvNeXt-Small 更轻：

```text
ConvNeXt-Tiny  depths = [3, 3, 9, 3]
ConvNeXt-Small depths = [3, 3, 27, 3]
```

因此 Tiny 可以明显减少深度分支计算量。

## 8. 融合模块

融合模块是：

```text
FusionNet_3Branch_UNet_FFT
```

低层特征使用频域融合，高层特征使用语义拼接融合。

频域融合将特征分为高频和低频：

```text
高频信息：边缘、纹理、局部细节
低频信息：整体轮廓、形状、结构
```

食物营养估计既需要食物类型和纹理，也需要整体份量，因此频域融合有助于同时利用局部和全局信息。

## 9. 预测头

当前预测头是：

```text
SharedNutritionHead
```

它不是原来的 5 个完全独立预测头，而是共享特征提取，再输出 5 个任务：

```text
[calories_kcal, mass_g, fat_g, carb_g, protein_g]
```

优点：

```text
减少重复计算
减少参数量
让多个营养指标共享食物类别、体积、纹理等信息
```

输出层使用 Softplus，保证预测值非负。

## 10. 训练流程

训练命令示例：

```powershell
python scripts\train_nutrition.py --dataset nutrition8K --data_root_8k .\data\0-OminiFood8k --b 2 --epoch 150 --log .\logs\swin_t_320 --save_dir .\trained_weights
```

参数说明：

```text
--dataset nutrition8K         使用 OmniFood8K 数据集
--data_root_8k                数据集路径
--b                           batch size
--epoch                       训练轮数
--log                         日志目录
--save_dir                    权重保存目录
```

最佳权重保存路径由 `--log` 的最后一级目录决定。例如：

```text
--log .\logs\swin_t_320
-> trained_weights\swin_t_320\ckpt_best.pth
```

如果使用默认 `--log ./logs/train`，则保存到：

```text
trained_weights\train\ckpt_best.pth
```

## 11. 损失函数

训练时主要包含三部分：

```text
1. 五个营养指标的回归损失
2. RGB/Depth 模态对齐损失
3. 热量一致性约束
```

热量一致性约束使用：

```text
calories_kcal ≈ 9 * fat_g + 4 * carb_g + 4 * protein_g
```

这个公式对应千卡 kcal 单位。

## 12. 测试流程

测试命令：

```powershell
python scripts\test.py --dataset nutrition8K --data_root_8k .\data\0-OminiFood8k --b 8 --ckpt .\trained_weights\swin_t_320\ckpt_best.pth
```

测试会输出：

```text
Calories MAE
Mass MAE
Fat MAE
Carb MAE
Protein MAE
Mean MAE
PMAE
```

MAE 表示平均绝对误差，PMAE 表示相对误差。

## 13. 推理流程

单张图片推理：

```powershell
python scripts\infer_nutrition.py --img-path .\food\fqcd.jpg --ckpt .\trained_weights\swin_t_320\ckpt_best.pth --depth-ckpt .\pth\depth_anything_v2_vitl.pth --save-depth
```

文件夹批量推理：

```powershell
python scripts\infer_nutrition.py --img-path .\food --ckpt .\trained_weights\swin_t_320\ckpt_best.pth --depth-ckpt .\pth\depth_anything_v2_vitl.pth --save-depth --batch-size 8
```

推理输出保存到：

```text
outputs\infer_nutrition\predictions.csv
```

CSV 字段包括：

```text
image
image_path
depth_path
calories_kcal
mass_g
fat_g
carb_g
protein_g
```

## 14. 当前优化点

当前项目已经完成以下优化：

```text
1. Swin-B 风格改为 Swin-T 风格
2. ConvNeXt-Small 改为 ConvNeXt-Tiny
3. 输入分辨率从 384 改为 320
4. 5 个独立预测头改为 SharedNutritionHead
5. 输出使用 Softplus 保证非负
6. 修正测试阶段预测头 eval 状态
7. 修正 fat_loss 动态权重 bug
8. 修正 alignment loss 位置
9. 推理阶段严格加载 checkpoint
10. 推理 CSV 增加 image_path 和 depth_path
11. 文件夹推理排序
12. 营养模型支持 batch 推理
```

## 15. 从数据到结果总结

完整流程可以概括为：

```text
1. 读取 train_new333.txt / test_new333.txt
2. 根据 sample_id 找到 RGB 图和深度图
3. 将图像 Resize 到 320x320 并归一化
4. RGB 图进入 Swin-T 提取特征
5. 深度图进入 DepthAdapter + ConvNeXt-Tiny 提取特征
6. RGB/Depth 特征进入 FFT 融合模块
7. SharedNutritionHead 输出 5 个营养值
8. 训练时根据标签计算损失并更新参数
9. 测试时计算 MAE/PMAE
10. 推理时输出 predictions.csv
```
